## Parafrase #1
- **Query:** Paket saya dimana, ko nda nyampe?
- **FAQ top-1:** Bagaimana jika paket saya belum sampai melebihi estimasi? (skor 0.758)

**Jawaban AI:**

Halo! Untuk mengetahui posisi paket Anda, nomor resi akan muncul di halaman 'Pesanan Saya' setelah barang dikirim, dan dapat digunakan untuk melacak di website kurir terkait. Jika status pengiriman tidak berubah, disarankan menunggu 1x24 jam karena bisa jadi ada keterlambatan update sistem kurir. Namun, jika paket Anda belum sampai melebihi estimasi pengiriman lebih dari 3 hari, mohon hubungi customer service kami dengan menyertakan nomor resi untuk ditelusuri lebih lanjut. Terima kasih.
